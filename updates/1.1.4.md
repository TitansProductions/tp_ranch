# What has been updated?

## Changelog - (Added, Fixed, Removed):

1. **Added** support for TP Ranch Creator to remove all ranch animals and objects while a player is editing a ranch. This prevents existing animals and objects from interfering with the editor's animals and objects.
2. **Added** new permissions for ranch members, giving ranch owners more control over what each member can access and manage.
3. **Added** a new invitation dialog to the NUI when adding a ranch member. Members are no longer added automatically and must now accept an invitation before joining the ranch.
4. **Added** an option to prevent animals from consuming water or food during nighttime/resting hours. Players will also be unable to perform activities such as milking, shearing, and similar actions during this time. Animals will use a resting scenario instead of a sleeping scenario, as the sleeping scenario made them appear dead.
5. **Added** a new livestock system for purchasing animals. Animals can now be purchased through the dedicated livestock trader instead of the ranch management menu.The same is for selling animals, you now sell them through a livestock trader.
6. **Added** a new server-side escrow function that allows developers to handle the money paid by players when ordering animals, such as depositing the payment into another system.
7. **Added** a new leveling system that allows players to unlock additional benefits as they progress.
8. **Added** TP MyDog support. When enabled, animals will follow the player's dog to the herding points instead of following the player directly. You can also add support for your own dog system through the `GetDogCompanyEntity` function in `client/escrow_ignore.lua`.
9. **Fixed** an issue with the happiness level during animal herding. The system was not properly detecting wolf attacks, which caused the happiness level to not be reduced correctly.
10. **Fixed** an issue with the maximum ranch member limit. The system was not properly checking the configured maximum number of members, allowing more members to be added than intended.
11. **Fixed** an issue with `RemoveDeadAnimalFromRanch` that prevented dead animals from being properly removed from the ranch when they died during herding.
12. **Fixed** an issue where ranch members could kick / remove the owner of the ranch from his ownership.
13. **Fixed** an issue with the breeding happiness check. The required happiness level was not being checked correctly, which allowed animals to breed even when their happiness was below the configured requirement.
14. **Improved** the breeding system by adding additional checks for the required happiness level.
15. **Improved** the breeding happiness system so that happiness is now properly removed from both male and female animals after breeding.
16. **Improved** the breeding requirements to properly check the minimum required happiness level for both males and females before allowing breeding.
17. **Improved** the selling of the animals no longer gives the money to the player, neither the item rewards of the animals, they are now delivered on the ranch itself (storage & ledger).
18. **Removed** the `Stores` parameter from `config_animals.lua` for all animal categories. This parameter was no longer functional, even when configured. Animal prices are now managed through `config_livestock.lua`.
19. **Removed** `Config.AddHungerCapacityOnHaybaleDeliver` from `config_animals.lua` file - haybale and corn deliveries are also removed from `config.lua` file, they are no longer supported.
20. **Removed** Haybale deliveries and corn deliveries, checkout notes for adding the new animal data and database table.

7. In case you want to keep `client/escrow_ignore.lua` file, add the following:

```lua
GetDogCompanyEntity-- This is the function that is used to get the dog companion from tp_mydog, you can have tp_mydog active on config and use your own 
-- functions getting the spawned dog companion from the desired script.
--- @return requires an entity.
function GetDogCompanyEntity() -- 1.1.4
	local dog_data = exports.tp_mydog:GetDefaultCompanion()

	local entity = 0

	if dog_data then 
		entity = dog_data.entity

		if entity == nil then 
			entity = 0
		end
	end

	-- If we get entity data but entity doesnt exist, we return as invalid.
	if entity ~= 0 and not DoesEntityExist(entity) then 
		entity = 0
	end

	return entity

end

function RegisterLivestockNPCEntityTargetAction(storeIndex, entity) -- 1.1.4
	local _entity = entity
	local v = Config.LivestockLocations[storeIndex] -- retrieving data by storeIndex
	local PlayerData = GetPlayerData()

	local options = {
		{
			label = v.StoreName,
			icon = v.TargetIcon,
			distance = v.TargetDistance,
			radius = v.TargetDistance,

			onSelect = function(data)
				TriggerEvent("tp_ranch:client:livestock:open_dialogue_options")
			end,

			description = ""
		}
	}

	exports.ox_target:addLocalEntity(_entity, options)
end
```
