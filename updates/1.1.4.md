# What has been updated?

## Changelog - (Added, Fixed, Removed):

1. Fixed an issue with happiness level on animal herding, the system would not read properly if wolves attacked while herding to remove happiness.
2. Added support for TP Ranch Creator to remove all ranch animals and objects when a player is on editor so the player will be able to edit a ranch properly, otherwise objects and animals would bug with the editor's objects and animals.
3. Added new permissions for the ranch members.
4. Added invitation dialog nui when a player wants to add member to the ranch, it no longer adds the member automatically but it sends a request instead.
5. Fixed an issue with max members - the system would actually never check for maximum members limit.
6. Added a new feature for the animals to not consume any water, food and also prevent players from milking, shearing, etc during night hours. The animals during rest hours (night time) will be having a resting scenario - not sleeping scenario, sleeping scenario makes the animals look dead.
7. Added a livestock system for purchasing animals and not through the management menu.
8. Removed `Stores` option parameter on `config_animals.lua` on every animal category, this is not functional even if you don't remove it. The cost for the animals will be modified from now on `config_livestock.lua` file.
9. Added new function server escrow file in case someone wants to deposit the money that a player paid for ordering animals.
10. Added leveling system to unlock more benefits.
11. Added TP MyDog support in case someone is running this script, this option will make the animals to follow the player's dog to the herding points instead of the player. You can also implement your own dog script through `client/escrow_ignore.lua` file on `GetDogCompanyEntity` function.
12. Fixed a mistake on `RemoveDeadAnimalFromRanch` which caused this feature to not work properly when an animal died on herding.
13. Fixed an issue related on `happiness` level, it was not checked properly on breeding, by that mistake, the happiness level was actually never checked for preventing breeding if it was lower than the required happiness level.
14. Added some extra checks and improved the breeding to remove happiness level from the males too and not only the females, also it used to not check for females minimum required happiness level, now it does.

```lua
GetDogCompanyEntity-- This is the function that is used to get the dog companion from tp_mydog, you can have tp_mydog active on config and use your own 
-- functions getting the spawned dog companion from the desired script.
--- @return requires an entity.
function GetDogCompanyEntity() -- 1.1.4
	local dog_data = exports.tp_mydog:GetDefaultCompanion()

	local entity = 0

	if dog_data then 
		entity = dog_data.entity

		if entity == nil then 
			entity = 0
		end
	end

	-- If we get entity data but entity doesnt exist, we return as invalid.
	if entity ~= 0 and not DoesEntityExist(entity) then 
		entity = 0
	end

	return entity

end

function RegisterLivestockNPCEntityTargetAction(storeIndex, entity) -- 1.1.4
	local _entity = entity
	local v = Config.LivestockLocations[storeIndex] -- retrieving data by storeIndex
	local PlayerData = GetPlayerData()

	local options = {
		{
			label = v.StoreName,
			icon = v.TargetIcon,
			distance = v.TargetDistance,
			radius = v.TargetDistance,

			onSelect = function(data)

				if not IS_PLAYER_ORDERING then 
                                
					local cb = exports.tp_libs:ClientRpcCall().Callback.TriggerAwait("tp_ranch:callbacks:canOrderAnimals", {} )

					if cb.allowed then

						if #cb.ranches > 1 then
							ORDERING_RANCHES_LIST   = {}

							OPENED_NUI_WINDOW_TYPE  = 'LIVESTOCK-NOTEBOOK'
							ORDERING_RANCH_NAME_ID  = cb.ranches[1]
							ORDERING_RANCH_INDEX_ID = 1
							ORDERING_RANCHES_LIST   = cb.ranches
							IS_PLAYER_ORDERING_LOCATION = storeId

							SendNUIMessage({ action = "livestock-start-dialog:set_info", locales = Locales, ranchId = cb.ranches[1] })

							EnableNUI(true, "livestock-start-dialog")

						else
							OPENED_NUI_WINDOW_TYPE  = 'LIVESTOCK-NOTEBOOK'
							ORDERING_RANCH_INDEX_ID = 1
							ORDERING_RANCH_NAME_ID  = cb.ranches[1]
							IS_PLAYER_ORDERING_LOCATION = storeId
							IS_PLAYER_ORDERING = true
							StartAnimalOrdering()
						end

					end

				else

					local orderListIsEmpty = IsOrderListEmpty()
					SendNUIMessage({ action = "livestock-finish-dialog:set_info", locales = Locales, is_empty = orderListIsEmpty })

					OPENED_NUI_WINDOW_TYPE  = 'LIVESTOCK-NOTEBOOK'
					EnableNUI(true, "livestock-finish-dialog")
				end

			end,

			description = ""
		}
	}

	exports.ox_target:addLocalEntity(_entity, options)
end
```
