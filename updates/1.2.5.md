# What has been updated?

## Changelog - (Added, Fixed, Removed):

1. Added an option to replace male Cow models with Bull models for more realistic ranch animal management (optional). The bull models will not be having any milking or actions.
2. Improved the `DEAD` text overlay on the dead / unconscious animals on the NUI, it was a very bad display, now it is has been redesigned to look much cleaner and better for fitting the NUI.
3. Fixed `GetGoatNearbyEntities`  attempt to call a nil value error for the goat animals.
4. Fixed an issue for some servers for some reason they couldn't reopen the chickens feedbag options after opening once.
5. Fixed invite cooldown duration on accept / decline nui callbacks because it seems that after kicking someone from the ranch and trying to re-add, the duration of the invite dialog was left as `1` second remaining and it was closing it request.
6. Fixed a bug where multiple players could do the fertilizer mixing action at the same time, this would make the fertilizing to bug and not work properly.

## Notes

1. Add the new feature related to male / female cows on the `config/config_animals.lua` below `Config.AnimalReviving` option.

```lua
-- Set to true to replace male Cow models with Bull models for a more realistic experience.
-- Keep in mind that Bulls cannot be milked or perform any cow-related actions.
-- Set to false to keep using Cow models for all animals, allowing male Cows to remain usable for milk production.
-- model: a_c_bull_01
Config.ReplaceMaleCowsWithBulls = false -- 1.2.5
```

2. Add new locales on `locales.lua`

```lua
['CANNOT_MILK_MALE_COW'] = { text = "The following animal does not produce any milk to start a milking action.", duration = 5}, -- 1.2.5
```

3. Replace from `locales.lua` the locale `MENU_FOOD_SECTION_ANIMAL_DEAD` from `DEAD` to:

```lua
	['MENU_FOOD_SECTION_ANIMAL_DEAD'] = "The animal is currently unconscious", -- 1.1.9
```
