# What has been updated?

## Changelog - (Added, Fixed, Removed):

1. Fixed an issue with happiness level on animal herding, the system would not read properly if wolves attacked while herding to remove happiness.
2. Added support for TP Ranch Creator to remove all ranch animals and objects when a player is on editor so the player will be able to edit a ranch properly, otherwise objects and animals would bug with the editor's objects and animals.
3. Added new permissions for the ranch members.
4. Added invitation dialog nui when a player wants to add member to the ranch, it no longer adds the member automatically but it sends a request instead.
5. Fixed an issue with max members - the system would actually never check for maximum members limit.
6. Added a new feature for the animals to not consume any water, food and also prevent players from milking, shearing, etc during night hours. The animals during rest hours (night time) will be having a resting scenario - not sleeping scenario, sleeping scenario makes the animals look dead.
7. Added a livestock system for purchasing animals and not through the management menu.
8. Removed `Stores` option parameter on `config_animals.lua` on every animal category, this is not functional even if you don't remove it. The cost for the animals will be modified from now on `config_livestock.lua` file.
9. Added new function server escrow file in case someone wants to deposit the money that a player paid for ordering animals.
10. Added leveling system to unlock more benefits.
11. Added TP MyDog support in case someone is running this script, this option will make the animals to follow the player's dog to the herding points instead of the player.
12. Fixed a mistake on `RemoveDeadAnimalFromRanch` which caused this feature to not work properly when an animal died on herding.

1. Replace old `Config.Management` configuration option to the new one:

```lua
-- Options in the ranch management menu to display / not based on your personal and server preferences.
-- (!) DO NOT MODIFY THE TYPE NAMES.
Config.ManagementMenu = {
    { Type = 'MENU_STATISTICS', Enabled = true,  BackgroundImage = 'statistics.jpg' }, -- shows all statistics related to the ranch. (version '1.1.4')
    { Type = 'MENU_LEVELING',   Enabled = true,  BackgroundImage = 'leveling.jpg'}, -- leveling section (1.1.4)
    { Type = 'MENU_BANKING',    Enabled = false, BackgroundImage = 'banking.jpg'}, -- ON  (version '1.1.4') IT MUST BE DISABLED - THIS OPTION IS NOW ON LEDGER.
    { Type = 'MENU_HERDING',    Enabled = true,  BackgroundImage = 'herding.jpg'}, -- animal herding
    { Type = 'MENU_BREEDING',   Enabled = true,  BackgroundImage = 'breeding.jpg'}, -- animal breeding
    { Type = 'MENU_LEDGER',     Enabled = true,  BackgroundImage = 'ledger.jpg'}, -- deposit or withdraw money from the ledger or set TP Banks state.

    { Type = 'MENU_TRANSFER',   Enabled = true,  BackgroundImage = 'transfer.jpg'}, -- transfer the ranch to another player
}
```

2. Add the night support feature on `config_animals.lua` below `Config.AddHungerCapacityOnHaybaleDeliver`.

```lua
-- Set to true if you want the animals to not consume any water, food, poop and also prevent players from herding, starting a breeding, milking, shearing, etc during night hours.
Config.NightTimeResting = { Enabled = true, From = 22, To = 6 } -- version 1.1.4
```

3. Add the new database table for livestock feature, this must be inserted on mysql / heidi query.

```sql
CREATE TABLE IF NOT EXISTS `tp_ranch_livestock` (
  `name` varchar(50) NOT NULL,
  `animals` longtext DEFAULT '{}',
  `orders` longtext DEFAULT '{}',
  PRIMARY KEY (`name`) USING BTREE
) ENGINE=InnoDB DEFAULT CHARSET=utf8 COLLATE=utf8_general_ci ROW_FORMAT=DYNAMIC;
```
