## Notes:

1. Add on `config_animals.lua` below `Config.AnimalDiseases` the new configuration option for ranch animal reviving system:

```lua

-- Added on 1.2.1 version - animal reviving system.
Config.AnimalReviving = {

    -- Set to false to disable the reviving system for ALL ranch animals.
    Enabled = true,

    Prompt = { key = 'ENTER', label = 'Apply Injection' },

    -- Set Jobs = false to allow everyone to be able to revive a ranch animal with @Item.
    Jobs = { 'medic' },

    -- The supported animal models on a ranch to be able to be revived.
    Animals = {
        --'a_c_chicken_01',
        'a_c_goat_01',
        'a_c_sheep_01',
        'a_c_cow',
        'a_c_pig_01'
    },

    -- DO NOT ADD THE SAME SYRINGE AS THE ANIMAL DISEASES SYRINGE OR ANY OTHER SCRIPTS HAVE, MUST BE A UNIQUE ITEM AND BE USED ONLY ON OUR SCRIPT AND ONLY FOR REVIVING.
    Item = "animal_revive_syringe",
    ErrorNotify = { notify = "You need an animal syringe item to apply on the animal for reviving.", duration = 4 },

    ActionDistance = 1.2,

    ApplyAnimation = {
        Type = 'ANIMATION', -- SCENARIO, ANIMATION (Available Types).
        Dict = "mech_revive@unapproved", -- Animation Dict or Scenario Name.
        Name = "revive", -- Animation Base Name if type is ANIMATION.
        ApplyingDisplayText = "Applying syringe...",  -- Set to nil to prevent displaying progress bar text and its delay system.
        AppliedDisplayText = { text = "You have successfully applied a syringe.", duration = 4 },
        ApplyDuration = 3500, -- Time in milliseconds

    },
}
```
